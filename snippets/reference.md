# 参照スニペット（他プロジェクトへ貼る文面の正本）

以下を、デザインを参照したいプロジェクトの指示文に貼る。

---

デザインは design-library（https://github.com/manji6/design-library）に従うこと。

1. まず INDEX を読む: https://github.com/manji6/design-library/blob/stable/INDEX.md
2. ユーザーがデザイン名を指定したとき、または対象に既存デザインが無いときだけ使う。「おまかせ」の既定は資料ならエディトリアル（editorial）。
3. デザインの status が name-only のものは適用せず、その旨を報告する。draft は名指しのときだけ使い、宣言表で「未定」の要素に触れたら止まって報告する。
4. 図解が要る場合は diagrams/README.md の手順に従い、diagrams/index.md からパターンを選ぶ。必須の役割が埋まらないパターンは不適として選び直す。候補がすべて不適か name-only のときは、無理に当てはめず、手順の出口（図にしない／索引情報だけで分解して報告）を使う。
5. 成果物は quality.md に従う（実在しない数値や引用を作らない、トークン外の色を使わない、などの Floor は必須。AIの癖にあたる Reflex を外した場合は報告に理由を書く）。
6. 作業の報告には「使ったデザイン slug＋図解 slug＋design-library の版（INDEX 冒頭の「版:」）」を含める。
