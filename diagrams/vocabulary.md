# vocabulary — 図解の共通語彙

図解パターン全体で使う語彙を4層に分けて定義する。各パターンは使う役割だけを宣言し、全部を使う必要はない。

## 要素の役割（名詞）

| 語 | 意味 |
|---|---|
| 主体 | 変化や関係の当事者。その図の「持ち主」 |
| 状態 | 主体がその時どうなっているか |
| 段階 | 作業や過程のどこまで進んだか |
| 手順 | 次に何をするか（作業の単位） |
| 項目 | 並べて示す個々の要素 |
| 群 | 項目の集まり |
| 量 | 数、割合、大きさ |
| 軸 | 比較や位置の基準 |
| 領域 | 内と外を持つ範囲 |
| 境界 | 領域の境目。跨ぐことに意味がある線 |

近い語の違い: 状態は「主体がどうなっているか」、段階は「作業の進み具合」、手順は「次に何をするか」。混同すると選択を誤る。

## 関係（線や位置が意味するもの）

遷移、順序、因果、包含、対応、対立、所属。

1つの図の中で、同じ見た目の線が違う関係を意味してはいけない。パターンごとに「この図の矢印が意味するもの」を固定する。

## 合成操作（核パターンからバリエーションを作る操作）

| 操作 | 意味 |
|---|---|
| 並置比較 | 同じ構造の列を並べ、対応をそろえて違いを見せる |
| 分岐 | 1つの点から道が分かれる |
| 循環 | 末尾が先頭へ戻る |
| 入れ子 | 要素の中に同じ構造を入れる |
| 反復 | 同じ構造を繰り返す |

並置比較（合成操作）か比較系（系統）かの境目: 問いの主語が各列の中身の変化なら並置比較のバリエーション。主語が列どうしの差そのものなら比較系のパターン。

## 修飾（どのパターンでも使える）

| 語 | 意味 |
|---|---|
| 注釈 | 特定の要素や遷移に付く特筆事項。本筋の外に置く |
| 強調 | 読者に最も見てほしい要素。原則1つ。色に加えて色以外の手がかり（太字、太い罫、ラベル）を最低1つ併用する |
