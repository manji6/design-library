# design-library

資料・読み物・Webページを作るためのデザイン定義を格納する場所。

- **デザイン（様式）** は `designs/` に DESIGN.md 形式で置く。トークンの正本は各 DESIGN.md のフロントマターで、tokens.css はそこから生成する。
- **図解パターン** は `diagrams/` に置く。図解は描き方ではなく「情報の表現構造」を文章で定義する。こういう情報をまとめたいときに、どの図解の型が成り立つか、を引けるようにする。
- エージェント向けの入口は [INDEX.md](INDEX.md)。他のプロジェクトから参照するときの文面は [snippets/reference.md](snippets/reference.md)。

## 使い方（人間向け）

- デザインを指定するときは名前で言う（例: 「エディトリアルで」）。名前と slug の対応は INDEX.md の名前解決表にある。
- 図解は diagrams/index.md の「読者の問い」から引く。
- 公開サンプルの一覧は GitHub Pages のトップ（index.html）から辿れる。

## 方針

- トークンの必須度は3層（層0: 絶対に必要／層1: 使うなら対まで定義／層2: デザイン固有の拡張）。各デザインの DESIGN.md には要素の宣言表があり、「定義あり／持たない／未定」が明記される。
- サンプルに個人情報や実データは入れない（ダミーデータに寄せる）。
