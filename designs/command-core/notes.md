# notes — MAGIコア（command-core）

## 由来

運用中の Muse ダッシュボード（MUSE CORE）のデザインを、2026-11-26 に既存デザインの取り込みとして登録した。実物の Space から色・書体・部品を抽出し、実物に無い部分は DESIGN.md の宣言表で「未定」としている。status は draft。

## 実物との対応

- 実物の CSS 変数（--bg、--panel、--org など）を、DESIGN.md の tokens に正規化した。値そのものは実物のものを採用している。
- 実物のフォントサイズは 9px〜44px の細かい刻みだったが、トークンとしては代表値（note 11px、h3 19px、h2 24px、display 44px）に丸めた。細かい刻みは実物の都合であり、定義として固定しない。
- 合議パネル、起動シーケンス、ドックは実物の骨格そのまま。起動シーケンスは sample には入れていない（ダッシュボードの入口演出であり、部品としての再利用性が低いため）。

## 未定の部分

- 図解部品表: ダッシュボードに図解を適用する需要が出た時点で定義する。
- 面色と対の文字色: key を面で大きく使う場面が実物に無い。必要になった時点で対を決める。

## 運用メモ

- 実物のダッシュボードは週1回の自動更新で内容が差し替わる。デザイン定義の変更は実物ではなく、この repo 側で行い、実物へは次の制作時に反映する。
