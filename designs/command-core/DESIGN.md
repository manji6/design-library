# MAGIコア（command-core）

## Overview

運用状態を見せるダッシュボードのためのデザイン。黒に近い地に、罫線で区切ったパネルを並べ、状態を色とモノスペースのラベルで即断できるようにする。MAGIシステム風の意匠（3ユニットの合議表示、起動シーケンスのモチーフ）を骨格に持つ。読み物ではなく「今どうなっているか」を見る画面専用で、資料・文書には使わない（それは editorial の領分）。

取り込み元は運用中の Muse ダッシュボード（MUSE CORE）。実物から抽出した定義だけを書き、実物に無い部分は宣言表で「未定」としている。

### 要素の宣言表

| 要素 | 宣言 |

| 補助色 | 定義あり（colors.sub、colors.dim） |
| 状態色（意味グループ・層2） | 定義あり（colors.ok / warn / info / error） |
| タイポスケール | 定義あり（typography.size-*） |
| 字間 | 定義あり（typography.label-letter-spacing。モノスペースのラベル用） |
| 行長 | 持たない（ダッシュボードは行長で組まない） |
| 罫線 | 定義あり（border.width、colors.line、colors.line-2） |
| 余白スケール | 定義あり（spacing.s1〜s4） |
| ドック（上部ナビ帯） | 定義あり（layout.dock-height、Components） |

## Colors

- 地は #070708、パネルは #0E0F12 と #121317 の2階調、入力やチップの沈み込みは #08090B。
- 文字は ink #ECE9E2（見出し）、body #C9C4B8（本文）、sub #9C978C（補助）、dim #6B675F（最も弱い情報）の4段。
- キーカラーはオレンジ #FF6B00（と補助の #FF8A1E）。ドックの下罫、現在位置、要点にだけ使う。
- 状態色は意味で固定する: ok #35E065（正常）、warn #FFB000（注意）、info #00D9EC（情報）、error #FF3B30（異常）。状態色を装飾に使わない。状態は色だけでなく、ラベルの文言でも必ず表す。

## Typography

- 本文は Noto Sans JP、13.5px、行間 1.7。ラベル、数値、コード、状態表示は IBM Plex Mono（フォールバックは ui-monospace 系）。
- モノスペースのラベルは小さく（11px 前後）、字間 0.08em で組む。見出しは 19〜24px、表示用の大きな数字は 44px。
- 数字は tabular-nums で桁を揃える。ダッシュボードの数値は「読む」ものではなく「比べる」ものとして組む。

## Layout

- 冒頭にドック（上部に sticky で固定するナビ帯、高さ 80px、下罫は key の 2px）を置き、その下にパネルのグリッドを並べる。
- パネルは罫線 1px で区切り、内側余白は s2 を基準にする。パネルの見出しはモノスペースの小ラベルで置く。
- レイアウト型は1つだけ（ダッシュボード型）。editorial のワイド／シングルのような型の使い分けは持たない。

## Elevation & Depth

持たない。奥行きはパネルの階調（bg → panel → panel-2）と罫線で作る。ドックだけ、背景のブラーで浮き上がらせる。

## Shapes

角丸は 0。形は罫線で区切る四角が基本で、状態ドットだけ円を使う。

## Components

- ドック: 上部 sticky のナビ帯。地は半透明＋ブラー、下罫は key の 2px。左にロゴと名前、横にナビ項目をモノスペースで並べる。
- パネル: 状態の単位。罫線 1px、地は panel（強調時は panel-2）。見出しラベル＋内容で組む。
- ステータス行: ドット（状態色）＋ラベル＋値の1行。区切りは hairline の罫。
- チップ: 切り替えや絞り込みの小片。地は inset、罫は line-2、モノスペース 11.5px。選択中は罫と文字を key にする。
- KPI: 大きな数字（モノスペース 44px）＋小ラベル。数字の色は状態に応じて状態色を使う。
- 合議パネル（MAGI）: 3つのユニットを並べ、各ユニットの状態（色と文言）と全体の合議結果を見せる、このデザイン固有の部品。
- バッジ: 件数や状態の短い表示。状態色の文字＋同色の罫で組む。

### 図解部品表

未定。ダッシュボードに図解パターンを適用する需要が出た時点で定義する。

## Motion

動きは Web 専用の追加動作であり、規範ではない。

- 状態ドットのパルス、合議ユニットの点滅、起動シーケンス風の出現。
- 動きは状態の変化を知らせるためにだけ使う。装飾だけの常時アニメーションは置かない。
- prefers-reduced-motion では全て止める。

## Do's and Don'ts

- 状態は色と文言の両方で表す。色だけに頼らない。
- 状態色（ok / warn / info / error）を、状態と関係ない装飾に使わない。
- key（オレンジ）はドックの下罫、現在位置、要点だけに絞る。面を広く塗らない。
- 数値はモノスペースで桁を揃える。比例フォントで数値を並べない。
- 資料や読み物にこのデザインを使わない。文書は editorial で組む。
- ライト配色を作らない。このデザインはダーク専用である。
