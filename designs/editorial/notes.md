# notes — エディトリアルの意図と詳細

規範は DESIGN.md、tokens.css、editorial.css、sample.html にある。このファイルは意図の説明。

## Layout

- ページは「資料の地図」。本文の長文で運ばず、節・表・引用・脚注に分けて置く。
- マストヘッドのメタ情報表は、日付・対象・出典・版のうち資料に意味のあるものだけを出す。
- ティッカーは見出し級の項目がある資料だけに置く。全ての資料に付けるものではない。
- 章番号の朱は大きく置く。本文側の朱は key-text に限る、という色の役割分担がこのデザインの識別点。

## Components

- ルールドカードは「罫線で区切る」ための部品。影や角丸で浮かせる方向にはしない。
- 目次は節が多い資料（目安として章が4つ以上）で置く。scroll-spy は現在位置の手がかり。
- コピーボタンは、読者がそのまま再利用するテキスト（プロンプト、コマンド）にだけ付ける。

## Motion

- 動きは Web 専用の追加動作。紙に落としたとき、JS が無いとき、reduced-motion のときに、内容と読み順がそのまま残ることが前提。
- カウントアップは「初期値＝最終値」で書き、JS が動いたときだけ 0 から数える。数字そのものは HTML 側に最終値を置く。
- 章番号のパララックスは視差の小さい範囲に留める。
